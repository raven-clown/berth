# Code of Conduct

berth follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, keep criticism about the work and not the person, and do not harass anyone. This applies in issues, pull requests, discussions and anywhere else you represent the project.

## Reporting

If someone's behaviour worries you, contact the maintainer, [@raven-clown](https://github.com/raven-clown), privately using the contact details on their GitHub profile. Reports are kept confidential. The maintainer may warn, temporarily block or permanently ban anyone who breaks this code, following the enforcement guidelines of the Contributor Covenant.
